# Burgrs TV — 1,000 TV-show facts

This is a ready-to-import **1000-row list of spoiler-free, catalogue-based TV facts**, covering **250 series** already known to Burgrs TV.

- Data snapshot: 11 October 2026
- Source: Burgrs TV synced programme/episode metadata from TheTVDB, with show-level links to TheTVDB and TMDB in every row
- Columns: ID, show title, TMDB ID, TVDB ID, category, fact text, source URLs, spoiler level and snapshot date
- All entries are unique by fact text and generated only from recorded show/episode metadata
- These entries focus on debuts, episode titles, longevity, genres, origin, runtime and episode counts. **They are not 1,000 independently researched casting or behind-the-scenes anecdotes.**
- TheTVDB and TMDB records can change; review copy and source links before setting up automated publication. Counts are a snapshot, not live values.

No live application or database tables were changed by preparing this list.
